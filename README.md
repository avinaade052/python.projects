# python.projects

A collection of small Python projects built to practice basic programming concepts.

## Projects included

- `calculator.py` — simple arithmetic calculator
- `Dic_rolling_game.py` — dice rolling game
- `numsguessing 2.0.py` — number guessing game
- `pascal's tranglr.py` — Pascal triangle generator

## Requirements

- Python 3.8 or newer

## How to run

Example:

```bash
python calculator.py
```

Replace `calculator.py` with any file you want to run.

## Learning goals

- Practice Python syntax
- Understand loops, conditions, and user input
- Build small beginner-friendly projects
- Improve problem-solving and debugging skills
